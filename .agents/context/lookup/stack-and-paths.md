## Route→feature quick map

- Landing: `pages/index.tsx` + `components/defaultLanding/*` (i18n, theme toggle)
- Login/signup: `pages/auth/{login,join}.tsx`
- Post-auth shell: `pages/dashboard.tsx` → team pages (first team's dashboard)
- Team dashboard: `pages/teams/[slug]/dashboard.tsx` + `pages/api/teams/[slug]/dashboard.ts` — role-scoped aggregate (members, invitations, API keys, subscriptions, ERP link); restricted sections are `null`, never zeros; never exposes `erpAccessToken`/`hashedKey`
- Platform admin console (P5.2/P5.3/P5.4/P5.5/P5.6/P5.7): `pages/admin.tsx` (tenants + subscription status + ERP health + recent registrations) · `pages/admin/tenants/[teamId].tsx` (drill-down) · `pages/admin/users.tsx` · `pages/admin/revenue.tsx` · `pages/admin/rules.tsx` (per-plan module toggles) · `pages/admin/audit-logs.tsx`; data via `pages/api/admin/{dashboard,users,revenue,audit-logs,rules/*,subscriptions/[teamId]/*,tenants/[teamId]}` — all guarded by `requirePlatformAdmin`. See `architecture/admin-console` for the audit store + error contract, and `architecture/auth` for the ERP-down contract.
